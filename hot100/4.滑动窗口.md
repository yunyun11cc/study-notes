# 滑动窗口

## 思想

### 一、本质

用两个指针维护一个**连续区间 **，靠「增量更新状态」避免重复扫描，把 O(n²) 降到 O(n)。是同向双指针的一种。

### 二、什么时候用

看到三个信号：

-   **连续**子数组 / 子串（不是子序列）
-   求**最长 / 最短 / 个数 / 是否存在**
-   窗口变化时状态能**增量更新**

反例：含负数求和恰好为 k（不单调）→ 用前缀和 + 哈希。

### 三、两种类型

-   **可变窗口**：求最长 → 不合法就缩；求最短 → 合法就缩
-   **固定窗口**：窗口定长，每次右移一格，进一个出一个

### 四、三个必问

1.  窗口里维护什么状态？（和 / 计数 / 不同字符数）
2.  窗口合法的条件是什么？（决定 `while` 怎么写）
3.  答案在扩时更新还是缩时更新？（最长在缩后，最短在缩中）

### 五、正确性前提：单调性

`left` 和 `right` 都只往右走，每个元素最多进一次出一次，所以 O(n)。前提是「窗口变大/变小，条件单调变化」。不单调就别用。



## 3. 无重复字符的最长子串

题目描述：

>   给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长子串** 的长度。
>
>    
>
>   **示例 1:**
>
>   ```
>   输入: s = "abcabcbb"
>   输出: 3 
>   解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。
>   ```

思路：

1.很容易想到暴力解，对于一个 i 指向的字符，反复遍历后面的字符，如果 j 指向的字符和 i 相同，那么返回的长度就是 j-i+1，但是时间复杂度为$O(n^2)$

2.这里可以利用滑动窗口，这里不涉及到窗口左右摆动的情况，所以窗口大小是单调的，一直增大

3.由于判断的子串有字符不重复的特性，所以这里维护一个集合 set，用做判断当前 j 指向的字符有没有被加入到集合当中，如果没有就直接加入，j 向右移动；如果在集合中了，那么就要移动 i 来缩小窗口，直到缩小到窗口内没有重复的字符

易错：

这里不能只单纯的每次判断两端的字符是不是重复，因为右边扩进来的字符是有可能和窗口内的字符发生重复的，上面的思路，可以反复对集合哈希判断当前窗口内有没有重复的字符

````Python
def lengthOfLongestSubstring(s: str) -> int：
	ans=1 # 用来更新最大长度，初始值为 1
    i=0 # 窗口左节点
    res=set()
    
    for j in range(len(s)):
        while s[j] in res: # 如果s[j]在集合中，则将 i 不断向前挪动缩小窗
           	res.remove(s[i]) # 将当前i的元素移除
            i+=1 
    
        res.add(s[j])
        ans=max(j-i+1,ans)
        
    return ans
````







## 438.找到字符串中所有字母异位词

题目描述：

>   给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的 **异位词** 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。
>
>   
>
>   
>
>   **示例 1:**
>
>   ```
>   输入: s = "cbaebabacd", p = "abc"
>   输出: [0,6]
>   解释:
>   起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。
>   起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。
>   ```



思路：

1.解这道题最关键的地方，子串p的长度是固定的，所以当我们在主串里面搜索的时候，窗口的大小是固定的

2.不断的向右移动这个固定的窗口，来判断这个窗口内的子串是不是 p 的异位词

3.这里利用Counter()方法，Counter可以计算字符串每个字符出现的次数，返回的是一个字典

````python
def findAnagrams(s: str, p: str) -> list[int]:
    need=Counter(p)  # 	我们要做匹配的特征窗口的字符计数
    window=Counter(s[:len(p)]) # 我们当前遍历的窗口，初始化位置为p固定长度的窗口
    result=[] #最终结果
    
    if window==need:
        result.append(0) # 直接将当前窗口做匹配，如果匹配加入结果
    
    # 窗口开始移动
    for i in range(1,len(s)-len(p)+1): #从 1 这个子串遍历到最后一个长度为 p 的子串
        out_char=s[i-1] # 当前被窗口移除的字符
        in_char=s[i+len(p)-1] # 当前被窗口加入的字符
        window[out_char]-=1 # 移除字符计数减一
        if window[out_char] == 0: # 清除当前窗口中计数为 0 的字符
            del window[out_char]
        window[in_char]+=1 # 加入字符计数加一
        if window==need:
            result.append(i)
        
    
    return result
````
