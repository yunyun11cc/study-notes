# 双指针（Two Pointers）

## 思想



### 一、本质

用两个变量在序列上同向或相向移动，利用**单调性**或**分工机制**，避免嵌套循环回溯，把 **$O(n^2)$ 的枚举降到 $O(n)$**。

### 二、三大常见形态

| **形态**                 | **核心移动方式**                | **适用场景**                               | **常见代表题**                            |
| ------------------------ | ------------------------------- | ------------------------------------------ | ----------------------------------------- |
| **快慢指针（同向）**     | 两个指针同向移动，步频不同      | 原地修改数组、去重、过滤特定元素、链表判环 | 283. 移动零、26. 删除有序数组中的重复项   |
| **左右指针（对撞）**     | 一左一右相向而行，向中间靠拢    | 有序数组两数之和、回文串判断、盛水容器     | 11. 盛最多水的容器、15. 三数之和          |
| **滑动窗口（同向区间）** | 维护 `[left, right]` 有效子区间 | 连续子串/子数组统计、最值搜索              | 3. 无重复字符的最长子串、76. 最小覆盖子串 |

### 三、快慢指针的核心思想

1. **角色分工（探路 vs 占位）**
	- **`fast`（探路工）**：负责无条件向前扫描，专门挑选**有效数据**（过滤无效项）。
	- **`slow`（占位工）**：负责守住**下一个有效数字应该写入的坑位**。
2. **写准 `if` 的唯一定律**
	- **谁在动就判断谁**：`fast` 在 `for` 循环中前进，审视的对象永远是 `nums[fast]`。
	- **关注有效项，忽视无效项**：终极目标是保留有效元素，所以条件直接写 `if nums[fast] != target`，而不是去捕捉垃圾元素。
3. **双指针避坑**
	- 绝不写 `if nums[slow] == 0`，否则遇到开头全是非零元素时逻辑会死锁。
	- 交换完成后，`slow` 必须随之 `+1`，代表该位置已经落定，等待下一个有效数。



## 283.移除零

题目描述：

> 给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。
>
> 请注意 ，必须在不复制数组的情况下原地对数组进行操作。
>
>
> 示例 1:
>
> 输入: nums = [0,1,0,3,12]
> 输出: [1,3,12,0,0]

思路：

1. **暴力解法与痛点**：每遇到 `0` 就把后面所有元素前移一位并在末尾补 `0`，时间复杂度为 $O(n^2)$，核心痛点是元素被大量重复平移。
2. **双指针角色分工**：`fast` 是“探路工”，负责向前遍历寻找非零元素；`slow` 是“占位工”，负责标记并守住“下一个非零元素该写入的下标”。
3. **协作与交换原理**：`fast` 遇到 `0` 直接跳过；遇到非零数就与 `slow` 交换并让 `slow += 1`，从而把有效数字不断向前集中，同时将 `0` 顺次推向数组末尾。

````python
def moveZeroes(nums: list[int]) -> None:
    """
    Do not return anything, modify nums in-place instead.
    """
    slow=0 # 标记可能会被交换的位置
    for fast in range(len(nums)):
      if nums[fast]!=0: # fast 探查到非零元素就和 slow 交换位置
        nums[slow],nums[fast]=nums[fast],nums[slow]
        slow+=1
    
````

## 15.三数之和

题目描述：

> 给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0` 。请你返回所有和为 `0` 且不重复的三元组。
>
> **注意：**答案中不可以包含重复的三元组。
>
> 
>
> **示例 1：**
>
> 输入：nums = [-1,0,1,2,-1,-4]
> 输出：[[-1,-1,2],[-1,0,1]]
> 解释：
> nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0 。
> nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0 。
> nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0 。
> 不同的三元组是 [-1,0,1] 和 [-1,-1,2] 。
> 注意，输出的顺序和三元组的顺序并不重要。

思路：

1. 对于三个数的和可以写成：`nums[i]=-(nums[j]+nums[k])` ，对于遍历到的nums[i]，在它后面的子数组中利用双指针找到和为 `target=-(nums[j]+nums[k])` 的数。
2. 首先将数组排序，计算当前的和 `cur_sum=nums[left]+nums[right]` 。因为当前数组升序的原因，当 cur_sum<target 时，说明 `nums[left]` 小了，将左指针右移找更大的数；当 cur_sum>target 时，说明 `nums[right]` 大了，将右指针左移找更小的数。
3. 去重：每当找完 i 、left、right 指针要移动的时候先判断下一个要检查的数和当前的数是否相同，如果相同则筛去。
4. 由于排序的原因，当第一个数大于 0 时，后面的和不可能再小于 0 ，可以提前剪枝。

````python
def threeSum(nums: list[int]) -> list[list[int]]:
    nums.sort()  # 原地排序：O(n log n)
    result = []
    n = len(nums)
    
    for i in range(n - 2):
        # 1. 提前剪枝：最小数大于 0 时，三数之和绝不可能为 0
        if nums[i] > 0:
            break
            
        # 2. 对第一个数去重（避免重复组合）
        if i > 0 and nums[i] == nums[i - 1]:
            continue
            
        # 3. 双指针夹逼
        left, right = i + 1, n - 1
        target = -nums[i]
        
        while left < right:
            cur_sum = nums[left] + nums[right]
            if cur_sum == target:
                result.append([nums[i], nums[left], nums[right]])
                # 用 while 跳过所有重复数值
                while left < right and nums[left] == nums[left + 1]:
                    left += 1
                while left < right and nums[right] == nums[right - 1]:
                    right -= 1
                # 推进到下一个全新区间
                left += 1
                right -= 1
            elif cur_sum < target:
                left += 1
            else:
                right -= 1
                
    return result
````
